How the numbers were checked. In every statewide, federal, district and county race, each town's candidates, write-ins, overvotes and blanks add up to that town's total, and the town rows add up to the State's own totals. Bristol's Justice of the Peace counts match the 12 winners the Town Clerk reported on election night. Where voters could choose more than one candidate, the base is the ballot count times the number of seats, which is how the State reports it. Blank votes are unused slots, so a voter who marks one name in a vote-for-two race produces one blank.

What doesn't line up yet. The State's unofficial files disagree with each other in small ways. Its turnout report shows 311,082 ballots statewide while the Governor's race shows 311,441. For Addison County the same two figures are 19,887 and 19,889. Its amendment file adds up to 309,593 ballots statewide, so that file may not yet include every town's final count. Bristol's own numbers agree across all of these. Turnout on this page uses the turnout report. Race shares use each race's own total.

Ahead, not elected. The State's unofficial data doesn't mark a winner in most races, so this page tags the candidates in the top spots as ahead. Winners are final after the canvass, and a close race can still go to a recount.
